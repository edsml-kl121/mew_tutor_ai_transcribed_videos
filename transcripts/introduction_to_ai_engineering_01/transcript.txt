Analyst Data Science Data Engineering แล้วเราก็มีการไล่นะครับเรื่อง Python ตั้งแต่การทำ print เนี่ยมันคืออะไร variable มันคืออะไร Data type คืออะไร การทำ condition ฟังก์ชัน Data Structure ไฟล์กับโหลด แพ็กเกจ OP พวกนี้เรามีการทำแล้วก็มีการบ้านให้ทุกคนลองไปทำพวก read code นะครับกับ basic data structure algorithm homework มีการดูพวก command line interface ว่าเราจะ access ไฟล์สร้างไฟล์ลบไฟล์อะไรยังไงนะครับเป็น essential จริงจริงแล้วแน่นอนมันก็จะมี sheet sheet อยู่ว่า command ดีที่สุดมันคืออะไร แล้วก็มีการทวนเรื่องกิตหักพูดง่ายง่ายคือการทำงานร่วมกันเป็นทีมนะครับ การทำงานร่วมกันเป็นทีมมีการ Open Pull Request การ merge Pull Request การทำอะไรต่างต่างด้วย GitHub เป็นสิ่งที่เรา walk through กันในวันนี้นะครับ นี่ก็คือจะเป็น command ภาพใหญ่ละกัน ยิ่งเราทำไปเรื่อยเรื่อยแล้วยิ่งเก่งไปเรื่อยเรื่อย แต่คอร์ส session แรกอาจจะเป็น brief overview ให้เรามี tool ในการเริ่มต้นนะครับ อาจจะไม่ได้เป็นแบบ expert เลย แต่ว่าเป็นจุดเริ่มต้นที่ดีละกัน วันนี้ผมก็ลาไปเท่านี้นะครับสำหรับ session แรก ก็ถ้าใครชอบคลิปนี้หรือมี feedback อะไรก็สามารถบอกได้นะครับ แล้วเดี๋ยวผมก็จะไปปรับ ปรุงให้มันดีขึ้น แล้วเดี๋ยวเรามาเจอกันใน session หน้านะครับ
