เราก็จะเห็นว่าไลบรี่เนี่ยมันขึ้นมาให้เราเลยตามหน้าจอที่เห็นอยู่ตอนนี้ซึ่งเราจะเห็นว่าแพนดาสเนี่ยมันก็จะมีหลากหลายเวอร์ชั่นมากเลยนะครับพอเราอยู่ในโลกของการ develop แอปพลิเคชันหรืออะไรก็ว่ามานะครับมันจะมีเวอร์ชั่นน่ะไปมากมายเรื่อยเรื่อยนะครับแล้วมันก็จะมีฟีเจอร์ใหม่มาแทนที่เรื่อยเรื่อยนะครับเหมือนตอนที่ไอโฟนมันมีการอัปเดตนะครับ มันก็จะมีการเพิ่มฟีเจอร์หรือแก้บัคอะไรอย่างเงี้ยใหม่ใหม่อันเนี้ยไอ้พวกไพตอนไลบรี่เนี่ยก็ก็เหมือนกันนะครับไม่ต่างกันมีหนำซ้ำเนี่ยในตัวไพตอนไลบรี่อ่ะเราก็จะสามารถที่จะดูตัวอย่างในการใช้งานโค้ดพวกนี้ได้นะครับ เช่นเราอยากจะใช้เดต้าเฟรมต่างๆเนี่ยเขาก็จะมีตัวอย่างว่าเอ้ยเราจะใช้เดต้าเฟรมพวกนี้ยังไงเราจะมีตัวอย่างโค้ดให้เราเอาไปใช้เบื้องต้น อันนี้คือไปตอนหลายบรีแล้วเดี๋ยวเราก็จะได้ลองด้วยกันวันนี้นะครับเดี๋ยวเราจะมีการแฮนด์ออนด้วยกันวันนี้อันนี้ก็คือจะเป็นตัวอย่างเนาะแพนดาสไลบรีวิธีการใช้งานดอทคอลัมน์อะไรอย่างนี้นะครับให้ดูเป็นตัวอย่างแต่ไม่เป็นไรอันนี้ไม่ใช่จุดประสงค์หลักจุดประสงค์หลักที่ผมจะบอกเนี่ยคือยิ่งทุกคนน่ะทำงานที่มันคอมเพล็กซ์มากขึ้นนะครับคุณคงไม่ได้มีการอิมพอร์ตแค่หลายบรีตัวเดียว แต่คุณอาจจะมีการใช้ไพตอนไลบรี่พวกเนี้ยเยอะไปหมดเลยหลายอันมากๆนะครับในเวลาเดียวดังนั้นวันเนี้ยสิ่งที่คุณจะได้เรียนรู้ใหม่อีกอย่างหนึ่งเลยคือเรื่องของการสร้าง virtual environment อ่า virtual environment เนี่ยแบบอธิบายไวๆก็คือจะเป็นวิธีการที่เราสามารถที่จะแยก environment มาเลยสร้างแบบสร้าง environment อันหนึ่ง นะครับขึ้นมาสมมุติคุณมีหนึ่งโปรเจคอย่างเงี้ยคุณก็อาจจะแยกใช่ไหมครับว่าเอ่ออยากจะให้มันมีดีเพนเดนซี่ของนำพายแพนดาสและอื่นๆตามนี้อ่ะตามรูปซ้ายมือและอีกโปรเจคนึงเนี่ยคุณก็ค่อยไปแยกดีเพนเดนซี่นะครับการที่เราลิสต์ว่าเราอยากจะใช้ไลบรี่อะไรแล้วเวอร์ชั่นอะไรเนี่ยมันสำคัญมากนะครับให้มันสำคัญในมุมมองที่ว่าเรา เราจะได้ไม่มีการไปมันสำคัญในมุมมองที่ว่าเราจะได้ไม่มีการไปมีพวกของดีเพนเดนซี่คอนฟลิกอ่าวอยดีเพนเดนซี่คอนฟลิกเราก็ทำให้แต่ละโปรเจกต์เนี่ยมันมันมีการลีนไม่ต้องอินสตอร์ทุกอย่างในทุกในหนึ่งโปรเจกต์และนี่เล่าให้ฟังเฉยๆนะครับแต่ปัจจุบันเรารู้ก่อนก็พอว่าหนึ่งพวกแต่ละโปรเจกต์แล้วแยกเราเราต้องมีการแยกพวกดีเพนเดนซี่หรือการโหลดโหลด แต่ยิ่งเราเดเวลลอปไปมากขึ้นเรื่อยๆอ่ะครับในอนาคตอ่ะก็อาจจะได้เห็นในแล็บถัดมาว่าในหนึ่งโปรเจคเนี่ยมันสามารถที่จะแบ่งย่อยแบ่งย่อยแบบเป็นหลากหลายลิสต์ออฟดีเพนเดนซี่ในหนึ่งโปรเจคได้ยกตัวอย่างเช่นฟันเอ็นแอปพลิเคชันก็อาจจะมีดีเพนเดนซี่ของมันแบ็คแบ็คเอ็นก็อาจจะมีดีเพนเดนซี่ของมันนะแต่เราจะเริ่มง่ายก่อน เรื่องใหม่ก่อนก็คือว่าเราจะให้ทุกอย่างเนี่ยแต่ละโปรเจกต์เนี่ยมันมีดีเพนเดนซี่ของมันเองโปรเจกต์หนึ่งก็คือจะมีดีเพนเดนซี่ของมันเองโปรเจกต์สองก็จะมีดีเพนเดนซี่ของมันเองและเรื่อยๆลงมานะครับเดี๋ยวสิ่งที่เราจะได้เรียนรู้ก่อนที่เราจะไปลงโค้ดอะครับก็คือเรื่องของเว็บสเกรปิงเดี๋ยวผมขออินโทรดักชั่นทูเว็บสเกรปิง นิดนึงแล้วเดี๋ยวเราไปลดลงแฮนด์ออนกันแล้วเดี๋ยวเราค่อยกลับมาเจนเนอทีฟเอไอกันหน่อยเว็บสเครปิงเนี่ยคือการที่เราจะทำยังไงก็ได้ให้เราดึงคอนเทนต์นะครับหรืออินฟอร์เมชั่นจากเว็บไซต์ในอินเทอร์เน็ตมาให้ได้ให้เราได้อยากได้สิ่งที่เราต้องการสมมุติผมอยากจะดึงข้อมูลเกี่ยวกับราคาของลาซาด้าอะไรเงี้ยอันนี้ก็คือจะเป็นเว็บสเกรปิงครับทำยังไงก็ได้ให้เราดึงข้อมูลพวกนั้นน่ะตามสิ่งที่เราต้องการ วิธีตลาดก็คือวันนี้เราจะใช้วิวฟูซุปกันคือวิธีแรกทุกๆเว็บไซต์เนี่ยถ้าสมมุติเราเปิดไปในเว็บไซต์ได้เว็บไซต์นึงเนี่ยมันจะมีการใช้เฮชเทียมแอลอยู่ข้างหลังบ้านถ้าสมมุติไม่เชื่อผมต้องไปดูในเว็บไซต์นี้นะครับถ้าผมคิดขวาไปแล้วทุกคนทำตามได้แล้วกดอินสเปคอ่ะครับ มันจะเบสออนเอชทีเอ็มแอลโค้ดหมดเลยตามที่เห็นในหน้านี้ดังนั้นนะครับเราสามารถที่จะเลเวอร์เรจไลบรี่อย่างเช่นบิวตี้ฟูลซุปในการดึงเอชทีเอ็มแอลโค้ดเอชทีเอ็มแอลไม่ใช่โค้ดนะครับแต่ว่าเอชทีเอ็มแอลจากเว็บไซต์ใดเว็บไซต์หนึ่งแล้วดึงแบบข้อมูลที่เราต้องการลงมาได้ไม่ว่าจะเป็นเออไทโทอะไรอย่างนี้นะครับหรืออื่นอื่นที่เราสนใจหรือมันก็ยังจะมี ก็จะเริ่มจากตัวบิวตี้ฟูลซุกก่อนอ่ะโอเคเรามาต่อกันนะครับวันนี้เนี่ยเราจะมาใช้ repository นี้นะครับก็คือจะเป็น repository ตัวเดิมเลยสิ่งแรกที่อยากจะให้ทุกคนทำก่อนก็คือเข้าไปในโฟลเดอร์ที่เรียกว่าศูนย์สองแอปพลิเคชั่นออฟไพตอนเราผ่านศูนย์หนึ่งมาแล้วนะครับวันนี้เนี่ยผมเข้าใจว่าทุกคนน่ะมีความสามารถในการใช้กี่ฮับอยู่แล้วแล้วมีการโคลน Repository ตัวเนี้ยลงมาในเครื่องตัวเองอยู่แล้วนะครับถ้ายังไม่ได้โคลนลงมาก็สามารถกินโคลน Repository นะลงมาในเครื่องของคุณได้เลยแล้วแบคทีเรียต่างต่างเนี่ยก็จะอยู่ใน VS Code คุณอย่างงี้เลยทวนวิธีการที่เราจะเข้าไปใน Repository ตัวเนี้ยได้นะครับก็คือว่าเราก็เข้าไปในไฟล์ที่เราสนใจนะครับเช่นตอนเนี้ย เราอาจจะอยู่ในเบส directory เราแค่ต้องเข้าไปในศูนย์สองผ่านเทอร์มินอลของเราเนาะโดยการพิมพ์ศูนย์สองแอปพลิเคชันออฟไพตอนแล้วก็พิมพ์ว่าโค้ดสเปซจุดอย่างที่ผมมีการแชร์ไว้ในเซชั่นแรกเนาะแล้วเราก็จะพร้อมและทุกอย่างก็จะอยู่ในเครื่องของเราซึ่งวันนี้เนี่ยรอบที่แล้วเนี่ยเรามีการรันโค้ดบนกูเกิลโคแลปใช่ไหมครับแต่รอบนี้เนี่ยเราจะรันโค้ด
