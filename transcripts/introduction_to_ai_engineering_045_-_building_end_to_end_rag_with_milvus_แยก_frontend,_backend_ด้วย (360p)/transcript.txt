Collection name ชื่อ Mill Collection และอยากให้ Collection เนี้ยมีสี่ Fields มี ID นะครับ ก็คือเป็น Unique ID Identifier แล้วก็ Title ก็คืออาจจะเป็น ไทโทของหน้านั้นแล้วก็ช่างคอนเทนต์ว่าแบบหนึ่งช่างเนี่ยมันมีอะไรบ้างกับเอ็มเบดดิ้งก็คือจะเป็นเวกเตอร์ที่มีไดเมนชั่นเจ็ดร้อยหกสิบแปดเนาะเพราะเราจะใช้เวกเตอร์เอ็มเบดดิ้งโมเดลที่มีไดเมนชั่นเจ็ดร้อยหกสิบแปดวันนี้แล้วแม็กเร้นพวกเนี้ยก็คือจะบอกว่ามารับเทคได้มากสุดคำเท่านี้นะสำหรับไทโทห้าร้อยสิบสองเร้นแล้วก็แม็กสำหรับช่างคอนเทนต์หน้าห้าพันหนึ่งร้อยเก้าสิบสอง ทีนี้เราลองมาไล่กันดูต่อครับคือตรงเนี้ยมันก็จะปริ้นว่าเอ้ยมันสร้าง collection ไปแล้วแหละมิว collection มันก็จะ list มาว่ามี collection อะไรบ้างทีนี้มันก็จะ list ออกมาว่ามีมิว collection ใช่ไหมทำให้เราเห็นตรงนี้นะครับเป็นมิว collection ถูกสร้างเรียบร้อยแล้วอันนี้ไม่มีอะไรครับผมแค่ลืมลบนะครับลบไปปึ๊บมันก็จะทำการอ่ารันรูปตรูช้าง Content นะฮะ ก็คือพูดง่ายๆคือมันจะฟอลรูปตัวไอ้ตัวช้างที่อยู่ในโฟลเดอร์ extraction ของเราอ่ามันจะฟอลรูปตัวคอลัมน์ช้างคอนเทนต์แล้วก็นะครับมันจะทำการเอ็มเบสแต่ละช้างให้กลายเป็นเวกเตอร์โดยผ่านตัวเก็บเอ็มเบดดิ้งฟังก์ชันนะครับที่อยู่ตรงนี้ก็คือเป็นฟังก์ชันที่รับเทคมาแล้วก็คืนเป็นเวกเตอร์นะครับ เสร็จแล้วมันก็จะทำการพูดง่ายง่ายคือ ingest data พวกเนี้ยนะครับเข้าสู่ Vector database และทำอะไรที่เรียกว่า indexing ซึ่งผมมองว่าไอ้จุด indexing เนี่ยก็เป็นอะไรที่สำคัญมากมาก indexing เนี่ยครับมันจะเป็นวิธีละกันที่ทำให้เราสามารถที่จะเก็บข้อมูลหรือเก็บ text แล้ว vector ใน vector database เราสามารถค้นหามันได้เร็วยิ่งขึ้นนะ มีหลายอย่างที่เราต้องรู้เลยเดี๋ยวเราค่อยค่อยไล่มาทีละอันนะ อย่างตัวเวกเตอร์เบสเนี่ยครับอย่างที่สำคัญที่ควรจะรู้เนี่ยคือมันจะมีเมทริกซ์ในการดูความไกลนะครับของเวกเตอร์แต่ละเวกเตอร์เนาะอย่างเช่นแอลทูโคไซน์แล้วก็ไอพีก็คืออินโนโปรดักส์นะครับแอลทูมันเป็นยูคิเดียนก็คือยิ่งแวลูต่ำก็คือยิ่ง แปลว่ามันจะมีความใกล้เคียงกันนะครับแปลว่าเวกเตอร์สองเวกเตอร์เนี่ยจะใกล้เคียงกันแล้วมีความหมายใกล้เคียงกันมากขึ้นแต่ละเวกเตอร์เนี่ยก็จะแต่ละเมทริกซ์ก็จะมีความหมายไม่เหมือนกันแต่ว่าโดยภาพใหญ่ที่เราควรจะรู้คือเมทริกซ์เนี่ยมันจะบอกความใกล้หรือความไกลระหว่างเวกเตอร์เพื่อที่จะเขาจะได้เอาไปเทียบต่อว่าเวกเตอร์เนี่ยมันมีความใกล้เคียงกันกับคำถามหรือเปล่าอันนี้ก็คือจะเป็นเวกเตอร์ต่างๆ ตัวเมทริกซ์ต่างๆนะครับลองไปดูละเอียดเพิ่มได้ทีเนี้ยมันจะมีอินเด็กซ์ซิ่งเมตเต็ดหลายแบบนะครับแฟลตก็คือแบบเราทำการอินเจสทั้งหมดเลยเนาะเราก็เสิร์ชก็คือเสิร์ชมันหมดไปเลยแต่ว่าถ้าที่ผมใช้เนี่ยมันก็คือจะเป็นท่าที่มันออฟติมาส์หน่อยนะครับเรียกว่าไอวีแฟลตหรือมันจะทำให้เราเนี่ยสามารถที่จะกรุ๊ปตัวเอ็มเบดดิ้งได้นะ กรุ๊ปตัวเวกเตอร์ให้กลายเป็นคลัสเตอร์ได้ทำให้เราเสิร์ชได้เร็วยิ่งขึ้นนะครับแทนที่เราจะต้องมานั่งไล่เสิร์ชสมุดมีพันเวกเตอร์ใช่ไหมอันนี้เราจะเสิร์ชพันเวกเตอร์เนี่ยเราอาจจะเสิร์ชแค่ 10 หรือร้อยร้อยร้อยคลัสเตอร์เนาะแล้วก็ค่อยเสิร์ชในคลัสเตอร์อีกทีว่าอะไรใกล้สุดอะไรอย่างงี้มันจะได้ทำให้ตอนเสิร์ชเนี่ยมันใช้เวลาเร็วยิ่งขึ้นนะครับอันนี้คือจะเป็นข้อดีของอินเดสซิ่งนะครับ แล้วก็จะเป็นอะไรที่เขาชอบคุยกันบ่อยบ่อยหรือถามบ่อยบ่อยด้วยว่าอะไรคือ indexing มีไว้เพื่ออะไรในเทคนิคคลอินเทอร์วิวนะครับก็ถ้าเขาถามก็บอกว่า indexing อย่างเช่นไอวีแฟลตเนี่ยมันช่วยให้เราทำการคลัสเตอร์ตัวเวกเตอร์นะครับได้และตอนที่เราเสิร์ชเนี่ยเราจะเสิร์ชเป็นคลัสเตอร์นะครับทำให้มันใช้เวลาเสิร์ชได้น้อยลง โอเคทีนี้เราพูดมาเยอะแล้วเรามาดูตัวเดต้าที่ถูกสตอกกันดีกว่านะผมรีเฟรชหน้าเห็นได้ว่าตัวมิวคอลเลคชั่นเนี่ยมันโผล่มาเรียบร้อยแล้วนะครับเราก็จะเห็นว่าตัวสกีมาเนี่ยมันตามที่ผมเขียนไว้เลยนะครับในตัวเอกสารในโค้ดของผมและอ่าเดต้าเนี่ยก็จริงๆก็ อ่ะนี่ก็คือจะเป็นเดต้านะครับที่ได้ทำการอินเจสไว้เรียบร้อยเนาะอันนี้ผมก็เผลอแอดลงมาผิดแล้วกันแต่ว่าจะเห็นได้ว่าเนี่ยเห็นไหมมันมีตัวเอิ่มที่เราอินเจสกันไปเต็มหมดเลยเนาะเป็นไทยลีฟพอลิซีแล้วก็เป็นรายละเอียดของแต่ละช้างว่ามันคืออะไรรวมถึงเอ็มเวกเตอร์นะครับว่ามันเข้ามาอยู่ในยูไอนี้จริงๆทีนี้ก็จะจบกัน กันนะสำหรับการอินเจสเดต้าเข้าสู่เวกเตอร์เบสเราลองมาเทสสิ่งนี้กันดีกว่าครับคือเราก็เทสได้ไม่ยากนะครับเพียงแค่เรารันตัวครีรีดอทพายนี้วิธีการทำงานก็คือมันก็จะไปแอคทีเวทตัวมิววสใครเราก็ทำการโหลดคอลเลกชั่นเนมที่เรียกว่ามิวคอลเลกชั่นมาทุกคนก็สามารถเปลี่ยนให้มันเป็นชื่อของตัวเองได้เนาะเราก็เสิร์ชเทอมที่ผมจะป้อนลงไปเนี่ยก็คือจะเรียกว่าฮัลโลวแล้วมาดูกันว่ามันจะคืนอะไรมากับเรานะครับอ่า ลองมารันโค้ดกันดูให้ตอนเคยดอกถ่ายอันนี้ผมพิมพ์ว่าฮัลโหลแต่มันก็จะอาจจะคืนอะไรที่ไม่เกี่ยวข้องมาทีนี้ผมลองพิมพ์อะไรที่มันเป็นภาษาไทยหรือเกี่ยวข้องเพิ่มขึ้นดีกว่าครับเช่นนะพนักงานหญิงลาคลอดได้กี่วันเราก็ลองรันฝ่ายนี้ดู เราก็จะเห็นได้ว่ามันก็จะมีเอกสารให้สกอร์มาใช่ไหมสกอร์เนี่ยมันคือความใกล้เคียงหรือความแม่นยำในการมันมันน่าจะเป็นเร็วที่สุดและในเอกสารนี้อะไรอย่างนี้นะครับมันก็จะคืนเอกสารมาเต็มเลยขึ้นเอกสารมาเต็มเลยนะครับจะแม่นหรือไม่แม่นก็อีกเรื่องนึง นี้โมเดลที่ผมใช้เนี่ยจะเป็นโมเดลที่มันอ่าเรียกว่าไม่ได้เก่งภาษาไทยขนาดนั้นนะในหน้าวันนี้แต่มันฟรีก็เลยเลือกใช้นะครับก็คือจะเป็นตัวนี้อ่าตัวเท็กซ์เอเบดดิ้งศูนย์ศูนย์สี่ของกูโก้แต่จริงๆแล้วมันมีเอ็มเบดดิ้งโมเดลอีกมากมายที่เราจะสามารถเล่นได้นะครับที่เก่งกว่านี้นะครับเราสามารถเริ่มดูต้นเบื้องต้นได้ที่ตรงนี้เอ็มทีเอ็มทีอีบี หรือว่าแมสซีฟเท็กซ์เอ็มเบดดิ้งเบนช์มาร์คพอเรามาดูในนี้เราสามารถที่จะเห็นได้ว่ามันมีมันจะมีตัวโมเดลแรงกิ้งให้เราเลือกเยอะมากมากมายไปหมดเลยนะครับเดี๋ยวผมจะเปิดของประเทศไทยให้ดูด้วยอันนี้ก็คือจะเห็นว่ามันมีรีเดอร์บอร์ดนะครับ ในตัว embedding model ต่างต่างก็จะบอกว่า embedding model สมัยเนี้ยตัวไหนมันดีบ้างนะครับ เราก็สามารถที่จะเอา embedding model พวกเนี้ยมาทำการ embed เพื่อให้ความ search หรือความแม่นยำในการ search เนี่ยมันดียิ่งขึ้นได้ นี่ก็คือจะเป็น embedding model นะครับที่คนไทยทำก็สามารถอ้างอิงจากความแม่นยำพวกนี้ได้นะครับสำหรับเอกสารภาษาไทยเนาะ อันนี้ก็จะหมดแล้วนะครับสำหรับส่วนของตัวอินเจชั่นแล้วก็ลองเทสถามคำถามมานะครับโดยเราทำแบบคร่าวๆละกันไม่ได้เลือกโมเดลที่ดีที่สุดแต่ถูกที่สุดอ่าเดี๋ยวเดี๋ยวเราจะมาต่อกันในตัวการสร้างแบ็คเอ็นเซอร์วิสแล้วค่อยฟันเอ็นเซอร์วิสละกันโอเคครับหลังจากที่เราได้ทำการอินเจสเดต้าเข้าไปแล้วเนี่ยเดี๋ยวเราจะมา เข้าสู่อีกจุดหนึ่งนะครับก็คือจะเป็นจุดของการ start ตัว backend service รอบนี้เนี่ยเดี๋ยวเราจะมาต่อกันโดยที่ว่าเราจะมา spin up ตัว Fast API Server นี้นะครับที่โดยที่ Fast API Server เนี่ยมันจะทำหน้าที่ในการหนึ่งคือ search จากถ้ามี user question ออกมาใช่ไหมมันก็จะ search จากคำถามของ เราก็จะคืนเสิร์ชรีสอร์ทให้เรานะครับป้อนสู่ราชแลงเวจโมเดลของเราแล้วมันก็จะมีการรับพวกเครนโชคต่างๆที่เราทำขั้นตอนก่อนหน้านั้นนะครับไม่ว่าจะเป็นซีรีส์ยูอาร์แอลหรือโทเก้นในการแอคทิเวทตัวมีว่าใครโอเคเพื่อไม่ให้เป็นการเสียเวลาเราจะลองมาเปิดตัวนี้กันนะครับตัวแบ็กเอ็นเซอร์วิสกันวิธีก็คือ เราเพียงเข้าไปที่ตัวแบ็คเอนด์แอปนะแล้วเราก็อาจจะสร้างเอ็นฟาร์เม้นท์นะครับในของแบ็คเอนด์เสร็จแล้วเราก็จะทำการแอคทิเวทตัวเอ็นฟาร์เม้นท์ของแบ็คเอนด์ของเราแล้วเราก็จะอินสตอลสิ่งต่างๆที่อยู่ข้างในรีควายเมนต์ดอทเท็กซ์ตัวนี้นะครับระหว่างรอมันอินสตอลเราก็จะเปิดอีกหนึ่งเทอร์มินอลนะครับแล้วเราก็จะไปทำการอิน Spin up ตัว front end เนาะ แล้วก็ระหว่างรอย install เรามาทำความเข้าใจตัว front end ก่อนนะครับคือตัว front end เนี่ยมันก็จะมีไม่มีอะไรมากเลยครับมันแค่จะเป็นหน้าหน้าต่างอันหนึ่งให้เราเรียกว่าส่งคำถามเราไปผ่านหน้านั้นแล้วก็ยิงเข้าสู่เรานะครับ local host แปดพันที่ในแชทเรา ในแชทพาสที่เราเพิ่งเห็นเมื่อสักครู่แล้วก็จะคืนเป็นแบบเรียกว่าจะคืนเป็นคำตอบนะครับของแอลเอ็มทีนี้เราลองมาสตาร์ทตัวฟอนเอ็นแอปนะครับระหว่างรอจริงๆแบ็กเอนเสร็จแล้วเราสตาร์ทตัวแบ็กเอนก่อนคือเราก็ถ้าเราจะทำการสตาร์ทตัวแบ็กเอนแอปเนี่ยสิ่งที่เราทำก็คือเราสามารถก๊อปคอมแมนนี้ได้นะครับยูวีคอนแอปโฮสต์ แปดพันรีโหลดอะไรงี้เราก็ก๊อปสิ่งนี้มานะครับเพื่อที่จะมาวางเลยแล้วมันก็จะทำการสตาร์ทตัวยูวิคอร์นแอปให้เราทีนี้อ่าโอเคครับถ้าใครไม่ได้ใช้ถ้าสมมุติว่าใครไม่ได้ใช้คอนด้านะครับก็แนะนำว่าให้พิมพ์คอมแมนตามนี้นอนคอนด้า เพื่อที่มันจะได้รู้ว่าเราจะแอคทิเวทยูวิคอร์นตรงไหนไม่งั้นถ้าเราใช้ตัวคอนด้าครับเราก็สามารถที่จะแอคทิเวทแอปได้อย่างนี้นะครับโดยถ้าผมพิมพ์ไปแล้วนะครับแบบนี้นะครับก็คือวีเอ็นวีบินยูวิคอร์นเนี่ยสิ่งที่เกิดขึ้นก็คือมันก็จะสตาร์ทแอปนะครับเราแปดพันมาให้เราถ้าผมเทสต์เอ็นพอยท์ตัวนี้นะครับในสักที่หนึ่งก็จะเห็นได้ว่าข้างหลังบ้านเนี่ยมันก็จะไปค้นหาเอกสารใช่ไหม แล้วมันก็จะเอ่อคืนกลับมาว่าฮัลโหลเจมนายเพราะว่าคำถามของเราก็คือเป็นฮัลโหลเจมนายเนาะทีนี้เราก็รู้แล้วว่าแบ็คเอนด์ของเราเนี่ยมันสำเร็จใช่ไหมถ้าให้มันง่ายอ่ะครับแล้วก็เข้าไปในหน้าฟอนเอนด์ของเรานะครับเราก็ทำการสร้างตัวเอ็นปาร์เม้นของเรา แล้วก็ทำการแอคทิเวทเอ็นพลอยเม้นท์นี้เราก็เพื่อที่จะสตาร์ทแอปก็คือสตรีมลิตรันแอปพลอตถ่ายได้เลยเท่านี้นะครับตัวแอปพลิเคชันของเราก็จะสตาร์ทเรียบร้อยถ้าสมมติผมถามไปว่าเออลีฟเดสหรือว่าอะไรที่เกี่ยวกับวันลาเนี่ยมาดูกันว่ามันจะทำอะไรเนาะ ข้างหลังบ้านเนี่ยมันก็จะไปค้นหาเอกสารที่เกี่ยวกับลีฟเดสนะครับนี่เอกสารพวกนี้แล้วก็มาสรุปให้เราเห็นได้อย่างเข้าใจง่ายยิ่งขึ้นเนาะหรือถ้าผมถามว่าเอิ่มเราไม่มีเดทแคนเฟกแนนซ์วูแมนลีฟเชฟ อ่ะนี่ก็จะบอกเราเนาะเป็นรูเมนเท็คลีฟด้วยเวลาเท่านี้นะครับหรือผมพิมพ์ภาษาไทยก็ได้พนักงานหญิงเพราะได้กี่วันอ่ะอันนี้ก็คืออาจจะเป็นไอ้ตัวเสิร์ชเมดิ้งโมเดลอาจจะไม่ได้เก่งมากขนาดนั้นนะครับเนื่องจากผมก็ไม่เลือกตัวที่ดีที่สุดแต่ไอเดียก็คือว่าเราเสิร์ชอะไรไปมันควรที่จะคืนสิ่งนั้นมายกตัวอย่างเช่นขั้นตอนในการล่า นะนี่ก็จะไล่ขั้นตอนในการลาให้เราไปใช้งานได้เบื้องต้นละกันนะครับโอเควันนี้นะครับก็หมดไปแล้วสำหรับตัวอย่างของการสร้างอ่าเรียกว่าเอ็นทูเอ็นเลยนะครับของตัวแรกแอปพลิเคชันที่มีทั้งฟันเอ็นเป็นสตรีมแบ็กเอ็นเป็นแฟสเอพีไอ แล้วก็นอกเหนือจากนี้ก็ยังจะมีตัวหลังบ้านเป็นมีวัดที่โฮสต์อยู่บนคลาวด์ที่เรียกว่าซีรีส์นะครับแล้วก็ได้เรียนรู้วิธีการเอาเอกสารมาแล้วก็ทำการชังกิ้งเอกสารเพื่อที่จะเอาเข้าสู่เวกเตอร์เบสวันนี้ก็ลาไปเท่านี้นะครับ
