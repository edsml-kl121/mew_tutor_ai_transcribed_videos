สวัสดีครับเดี๋ยววันนี้เนี่ยผมจะมาเล่านะครับเรื่อง Data Structures and Algorithm บางคนอาจจะเคยได้ยินนะครับ Data Structure and Algorithm มาแล้วว่ามันเป็นอะไรที่ต้องใช้ใน Coding Interview ต่างๆเดี๋ยววันนี้ผมจะมาปูพื้นฐานแบบคร่าวๆละกันที่จริงอะอยากจะเริ่มจากว่าทำไมนะครับทำไมเราจะต้องเรียนรู้เกี่ยวกับเรื่อง Data Structure and Algorithm ก่อนครับ Y จริงเหตุผลที่เราต้องเรียนรู้เกี่ยวกับเรื่องเดต้าสตรักเชอร์เนี่ยก็คือจะเป็นสองสองอย่างละกันนะอันแรกเลยก็คือสัมภาษณ์นะครับในมุมสายงานด้านซอฟต์แวร์เอ็นเจเนียร์แล้วก็อีกมุมนึงนะครับอ่ะซอฟเจเนียร์อะไรพวกนี้ก็จะมีการใช้พวกนี้แล้วก็อีกอย่างหนึ่งเลยเนี่ยก็คืออ่าจะได้เขียนโค้ดได้ไวขึ้นนะครับแฟสเตอร์โค้ดก็คือการที่เราฝึกซ้อมพวกเดต้าสตรักเชอร์เนี่ยมันทำให้เราเห็นโค้ด แล้วทำให้เราแบบรู้ว่าเออแบบแบบนี้แหละมันควรที่จะเขียนโค้ดแบบนี้นะมันจะได้รันได้เร็วยิ่งขึ้นเผื่อวันหนึ่งคุณไปเจอลาสเกลซิสเต็มแล้วมันจะต้องทำการออปติไมซ์นู่นนี่นั่นอะไรอย่างเงี้ยอันนี้ก็คือจะเป็นที่มาที่ไปว่าทำไมจะต้องเรียนรู้เดต้าสตรัคเชอร์อัลกอริทึมบางคนอาจจะมีความคิดเห็นว่ามันไม่จำเป็นแต่ผมมองว่ามันจำเป็นแต่แค่ไม่ต้องรู้ทุกอย่างก็ได้ไม่ต้องช่ำทุกอย่างแต่รู้ในส่วนที่สำคัญนะครับผมรู้สึกอย่างนี้ อะไรจะมาแชร์เริ่มแรกก่อนเดต้าสตรักเชอร์อัลกอริทึมเนี่ยคืออะไรมันก็แบ่งออกเป็นสองคำใช่ไหมครับเดต้าสตรักเชอร์อัลกอริทึมเดี๋ยวเราค่อยๆลงทีละอันโดยอันแรกเนี่ยก็คือจะเริ่มจากเดต้าสตรักเชอร์ก่อนเดต้าสตรักเชอร์เนี่ยมันเป็นวิธีการเก็บข้อมูลนะครับแล้วก็เก็บข้อมูลยังไงให้เราสามารถที่จะเซสเดต้าพวกนี้ได้เร็วยิ่งขึ้นเนี่ยก็คือจะเป็นเดต้าสตรักเชอร์มันจะมีหลากหลายที่เราจะได้เห็นนะครับเร็วๆนี้ แล้วก็อีกเรื่องหนึ่งก็คือเป็นนะครับสุดท้ายอ่ะพอมันมีคำว่ามันก็เหมือนกับว่าเราจะต้องทำการแก้แก้โจทย์สเต็ปไปสเต็ปก็เลยเป็นที่มาที่ไปว่าคนที่เดินเข้าไปในอินเทอร์วิวเนี่ยก็ต้องมีการรู้วิธีการเก็บข้อมูลนะครับโดยการใช้วิธีต่างๆแล้วก็เขียนโค้ดให้มันแก้โจทย์ให้ได้เร็วที่สุดโดยที่ออบเจคทีฟนะครับในการผ่านอินเทอร์วิวพวกเนี้ย มันก็คือจะเขียนโค้ดให้อ่าไทม์คอมเพล็กซ์ซิตี้นะครับอ่ะมันจะเป็นมันจะเป็นออกเป็นสองอย่างนะก็คือเป็นไทม์แล้วก็สเปซนะครับออกเช็ปทีฟก็คือว่าเราอยากจะมินิมายไทม์คอมเพล็กซ์ซิตี้แล้วก็สเปซคอมเพล็กซ์ซิตี้ให้โค้ดเนี่ยมันรันให้ได้เร็วที่สุดแล้วก็กินพื้นที่หรือมีพื้นที่ให้ได้น้อยที่สุดเพราะฉะนั้นเรามาดูกันเริ่มจากเบสตรักเชอร์ก่อน ในตัว data structure เนี่ยมันก็จะแบ่งออกเป็นหลากหลายวิธีการเก็บข้อมูลแล้วกันแต่ที่เราน่าจะคุ้นเคยที่สุดนะครับก็คือจะเป็นตัวลิสต์หรือ array เนอะจริงจริงผมอยากจะมองอยากให้ทุกคนมองอย่างนี้แล้วกันว่าอะไรที่มัน popular มากมากกว่ากันใน coding interview นะในประเทศไทยสิ่งที่ผมมองว่ามันค่อนข้าง popular แล้วก็เอาออกบ่อยนะครับในประเทศไทยก็คือจะเป็น list array stack Q stack Q dictionary พวกเนี้ยออกบ่อยบ่อยบ่อยมากครับ แล้วก็ส่วนที่อาจจะออกบ้างแต่อาจจะน้อยนะครับขึ้นอยู่กับความสะอาดของบริษัทก็คือจะเป็นพวกลิงก์ลิสต์ไปในทรีแล้วก็กราฟพวกนี้ก็มีออกบ้างแต่อาจจะค่อนข้างไปในทิศทางที่น้อยละกันเท่าที่ผมเจอมาแต่ก็มีบางไม่ใช่ไม่มีหลักๆแค่จะเป็นสีส้มพวกนี้มากกว่าเพราะฉะนั้นเราลองมาดูกันนะครับว่าแต่ละอันเนี่ยมันคืออะไรแล้วเราค่อยไปไล่ดูว่าสเปซแล้วก็ทานคอมเพล็กซ์ซิตี้เนี่ยมันคืออะไรอันนี้ต้องเป็นถามโอเค อย่างเช่นลิสต์เอเรย์เนี่ยมันจะเราน่าจะคุ้นอยู่แล้วใช่ไหมมันก็คือจะเป็นแบบเหมือนเราเก็บข้อมูลในอเรย์ถ้าใครยังไม่คุ้นชินก็สามารถที่จะไปดูหม้อดีลก่อนหน้านั้นได้ที่ผมเคยแปะไว้แล้วแล้วเราก็สามารถที่จะอเพนเอเลเมนต์เข้ามาในอเรย์นี้ได้ให้เราทำอะไรกับมันเช่นเราจะฟอร์รูปผ่านมันอะไรเงี้ยก็อันนี้ก็คือจะเป็นอะไรตรงไปตรงมาทีนี้ลิงค์ลิสต์ก็คืออาจจะเป็นอะไรที่คนที่ไม่ได้เรียนคอมพิวเตอร์ไซค์อาจจะไม่ค่อย ไม่เคยเห็นมาก่อนนะครับอันนี้มันเหมือนจะเป็นอารมณ์ว่าเราเก็บข้อมูลนะครับไว้แล้วมันจะมีแบบพอยท์เตอร์นะครับที่จะชี้ข้อมูลเนี่ยเข้าสู่โหนดถัดมาเรื่อยๆเรื่อยๆเรื่อยๆอันนี้ก็คือจะเป็นลิงค์ลิสต์แล้วกันใครอยากเข้าใจเพิ่มก็ลองไปอ่านเพิ่มหรือว่าแนะนำให้ทำโจทย์ก็แล้วกันแล้วก็ไล่มาก็คือจะเป็นแตกนะครับเอ่อลาสอินเฟิร์สเอาพูดง่ายๆคือจินตนาการว่าเนี่ยมันเป็นเอ่อที่เก็บหนังสือแล้วอ่าพอเราวางหนังสือเสร็จปุ๊บ สิ่งที่เราเกิดขึ้นก็คือว่าเราต้องเอาหนังสือที่อยู่ข้างบนออกก่อนถูกป่ะเราไม่มีทางนี้จะวางหนังสือสามอันแล้วก็ค่อยเอาอันสุดท้ายออกเนี่ยมันก็โครงสร้างมันก็จะลงหมดนะครับเอ่อมันก็เลยที่มาเป็นที่ใหม่ที่มาว่าอีสแตทเนี่ยคือลาสอินแล้วก็เฟิร์สเออทูโกเอาท์ยกตัวอย่างเช่นสมมุติว่าอันนี้มันเป็นอาเรย์นะครับในการเก็บแตกเราอาจจะใส่ตัวเลขสีเข้ามาแล้วเราอาจจะถอดตัวเลขสีออกไปนะครับโดยใช้คำสั่งท็อปในไพตอนเนี่ยก็คือจะเป็น ส่วนคิวเนี่ยก็คือตรงไปตรงมาเนาะก็คือแบบ first in first out แปลว่าถ้าสมมุติว่าคุณอยู่ในคิวกำลังต่อแถวอยู่ใช่ไหม สมมุติกำลังจะซื้อเบอร์เกอร์อยู่อย่างเงี้ยคุณก็ซื้อเบอร์เกอร์คุณต่อแถวคนแรกคุณก็ซื้อเบอร์เกอร์แล้วคุณก็ออกคนแรกก็เลย first in first out นะครับ เพราะฉะนั้นมันจะเป็นอารมณ์ว่ามันจะมีคนใหม่เข้ามาข้างข้างท้ายคิวแล้วก็ของคุณน่ะที่อุดหนุนคนแรกก็จะออกไปนะครับก่อนเนี่ยก็คือจะเป็นวิธีในการทำคิว ว่าคิวทำงานยังไงซึ่งเราอาจจะได้เจอสิ่งพวกเนี้ยอยู่ในเอ่อการการทำแก้โจทย์ก็แล้วกันมันก็จะมีดิกชันนารีครับหรือว่าเขาอาจจะเรียกกันว่าแฮชเทเบิลคือพูดง่ายๆเหมือนเป็นคีย์แวลูแพร์อย่างเงี้ยที่เก็บแบบว่าแอปเปิ้ลเนี่ยมันให้ตัวเลขหนึ่งชื่อเนี่ยเป็นมิวนู่นนี่นั่นอะไรเงี้ยเดี๋ยวซึ่งเดี๋ยวมันจะมีข้อดีของมันเดี๋ยวผมจะเล่าให้ฟังว่ามันคืออะไรเราก็จะมีพวกแบบ ใบเนรีทีนะครับที่เป็นต้นไม้แบบเนี้ยที่มันเกิดมาอาจจะมีหลายข้อดีไม่ว่าจะเป็นทำให้เสิร์ชเร็วขึ้นซึ่งเดี๋ยวเราจะได้เจอกันนะว่าเสิร์ชมันเร็วขึ้นยังไงแต่ว่าดูคร่าวๆเนี่ยคือถ้าสมมุติว่าผมพยายามที่จะหาตัวเลขสิบห้าสิ่งที่จะเกิดขึ้นก็คือผมจะต้องไปไล่หาเอ่อฟอร์รูปตัวห้าก่อนสิบก่อนแล้วค่อยสิบห้า แต่ถ้าผมอ่ะเริ่มจากใบนี้วิธีเลยอ่ะผมแค่บอกว่าเออสิบห้ามันมากกว่าหรือ น้อยกว่าสิบใช่ป่ะมันก็จะไปด้านขวาทำให้สเต็ปเนี่ยมันน้อยลงนะครับเรามาดูค่อยมาดูกันว่ามันเป็นทางคอมเพล็กซ์ซิตี้เท่าไหร่แล้วก็กราฟก็คือจะเป็นลักษณะนี้เนาะซึ่งผมค่อยเจอใครเจอก็คอมเมนต์มาได้ในอินเทอร์วิวเอิ่มทีนี้เราลองมาดูนะครับสเปซและทานคอมเพล็กซ์ซิตี้กันของสิ่งพวกนี้จะเห็นได้ว่าไอ้เจ้าตัวสูงมาหน่อยจะเห็นได้นะครับว่าเจ้าตัวลิสต์หรืออะไรเนี่ยมันจะมีตั้งแต่ ตั้งแต่อีบนเนี้ยนะครับลิสต์ลิงค์ลิสต์แตกคิวเนี่ยส่วนใหญ่แล้วมันจะมีสเปซหรือเสิร์ชเนี่ยโอโอเอ็นก็คือว่าคำว่าทางคอมเพล็กซ์เซฟตี้เนี่ยมันแปลว่าอะไรใช่ป่ะบางคนอาจจะถามคือบางคนอาจจะสงสัยว่ามันคืออะไรก่อนคือยิ่งนะครับเราสมมุตินะอันนี้เป็นกราฟสมมุติว่าเอาเรื่องทางก่อนแล้วกันครับสมมุติว่า จำนวนเอเลเมนต์ในอาเรย์ใช่ป่ะปึ๊บหนึ่งสองสามไปเรื่อยๆเรื่อยๆเรื่อยๆจะถึงเอ็นละกันอันนี้คืออะไรของคุณแล้วถ้าสมมุติว่าอาเรย์เนี่ยมันโตเรื่อยๆนะครับแล้วมีจำนวนเอ็นเนี่ยเราเอ็นเท็นทูอินฟินิตี้เนี่ยสิ่งที่จะเกิดขึ้นก็คือว่าเวลาในการรันโค้ดเนี่ยก็คือจะเท็นทูเวิร์ดโอเอ็น รวมถึงสเปซด้วยก็คือแบบเอ่อการเก็บข้อมูลก็จะเทนทูโอฟเอ็นนะแต่บางบางบางบางวิธีในการที่เราจะใช้เดดาสตรักเชอร์พวกเนี้ยมันก็จะสามารถทำให้มันเอ่อเคยมีข้อมูลได้เร็วยิ่งขึ้นนะครับคือคือทำว่าทางคอมเพล็กซ์ซิตี้ตรงนี้ก็คือชี้แจงก่อนว่าผมอยากรู้ว่าตัวที่เอ็นลบหนึ่งเนี่ยคือเอ็นเนี่ยคืออะไรผมก็ต้องนั่งฟอร์ลูกรูตั้งแต่แรกจนจบใช่ไหมจนกว่าจะได้โอฟเอ็นแต่สมมุติ
