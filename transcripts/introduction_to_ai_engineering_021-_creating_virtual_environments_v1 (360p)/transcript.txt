สวัสดีครับจุดประสงค์ของ session นี้นะครับก็คือจะเป็น session ที่จะปูพื้นฐานนะครับเรื่องของตัว Virtual Environment ของ Python ดูว่าทำไมเราต้องใช้ Virtual Environment แล้วมันคืออะไรแล้วเดี๋ยวเราจะมาลอง Hands on กันนิดหนึ่งนะครับในตัวอย่าง Option ถ้าเราจะเลือกใช้เช่น Python อย่างเงี้ยเราจะสร้าง Virtual Environment ยังไงแล้วมันมีประโยคยังไงไปดูกันเกริ่นก่อนนะครับในทุกโปรเจกต์ที่เราทำกันน่ะ มันก็จะไม่มีทางเลยที่เราจะเขียนทุกอย่างเองใช่ไหมเราจะต้องมีลายออนการเขียนลายดึงไรเบอร์รี่ที่มันสำเร็จรูปมาแล้วยกตัวอย่างเช่นแพนดาสนะครับไรเบอร์รี่เนี่ยเราอาจจะต้องใช้ไรบี้พวกเนี้ยเพื่อที่จะประหยัดเวลาในการที่เราจะทำงานมากยิ่งขึ้นแล้วปัญหาเนี่ยครับคือพอเรายิ่งทำงานเข้าไปเรื่อยๆๆๆใช่ไหมเราก็จะเห็นได้ว่าหนึ่งโปรเจคเนี่ยมันก็จะเริ่มมีดีเพนเดนซี่งอกมา มากขึ้นเรื่อยๆนะครับทีนี้มันก็โอเคเราก็สามารถอินสตอร์ทุกอย่างได้ในโปรเจกต์หนึ่งใช่ไหมแต่ปัญหาเนี่ยคือถ้าเราอ่ะมีอีกโปรเจกต์หนึ่งใช่ไหมครับแล้วเราอ่ะก็ยิ่งค่อยๆเพิ่มในเจ้าตัวดีเพนเดนซี่ด้านซ้ายไปเนี่ยมันจะเจอปัญหาอยู่สองอย่างด้วยกันอย่างแรกเลยเนี่ยคือจะเป็นฉันออฟดีเพนเดนซี่คอนฟิกแล้วก็ฮาร์เดอร์ทูแมนเนจ แปลว่ายิ่งดีเพนเดนซี่เยอะเนี่ยแล้วเรายิ่งแอดตัวเอ่อดีเพนเดนซี่เข้ามาในไฟล์รีคายเมตเทคไปเรื่อยๆเรื่อยๆเรื่อยๆเนี่ยมันก็จะยิ่งมีโอกาสที่มันคอนฟิกแล้วก็จริงๆเอ่อทำให้เสียเวลานะครับกินแต่ลองรันได้เพราะฉะนั้นน่ะเราควรที่จะให้หนึ่งโปรเจกต์มีเอนบายเมนต์ที่ลีนที่สุดอันนี้ก็คือเลยจะลีดถึงข้อที่สองของผมก็คือว่าเราควรที่จะ มีลีนนะครับหรือว่าดีเพนเดนซี่ลิสต์ก็ได้นะครับเพื่อที่จะให้เวลาหรือเวลาอินสตอลดีเพนเดนซี่เนี่ยมันช้าให้ไม่มากที่สุดเพราะว่าบางทีเนี่ยถ้าสมมุติว่าเราใช้ดีเพนเดนซี่หรือว่าไลบี้อย่างเซ็นเทนแพลนฟอร์เมอร์อะไรเงี้ยมันก็จะใช้เวลานานมากเลยกว่าเราจะอินสตอลเสร็จ เรายิ่งเราค่อยๆไปดูในมอดีลอื่นที่ผมจะมีการเกริ่นเอ่อถ้ามันมีแบบดีเพนเดนซี่ที่ไม่ค่อยไลฟ์เวทเนี่ยมันจะทำให้เวลาบิวหรือสร้างทำไปปลายหรือว่าทำการเอ่อบิวอิมเมจดอกเกอร์อิมเมจเนี่ยมันใช้เวลานานยิ่งขึ้นแต่นี้เราย้อนกลับมาก่อนเราขอย้อนกลับมาในพื้นฐานว่าถ้าเราอ่ะอยากจะสร้างเวอร์ชวลเนี่ยอ่ามันจะเป็นลักษณะไหน วิธีการแนะนำก็คือว่าเราควรที่จะต่อโปรเจกต์อะครับเราควรที่จะเนาะมีการแยก dependency รายอันเลยเช่นโปรเจกต์หนึ่งเนี่ยเราก็จะมี dependency ตามนี้โปรเจกต์สองเนี่ยเราก็อาจจะมี dependency ตามนี้นี้ซึ่งอันเนี้ยที่ผมเล่ามันจะเป็นระดับโปรเจกต์เนาะแต่เดี๋ยวหลังจากเนี้ยเดี๋ยวจะได้เห็นว่ามันจะมีระดับสวิตช์ด้วย ซึ่งตรงเนี้ยจะอยู่ในเรื่องของ Containerization นะครับวันนี้อาจจะไม่ได้ลงจุดนี้ นิดนึงครับ ผมอยากจะบอกว่าคอนเซ็ปต์เรื่องการแยกเพอร์โชล environment อะไรเงี้ยมันจะเป็นมุมมองของแบบคนกำลังพัฒนาอยู่อยู่ในเดฟสเตจนะครับ พออยู่ในโปรดักชั่นสเตจมันค่อยจะไปยุ่งเรื่องของคอนเทนเนอร์ไรเซชั่นนะครับ ซึ่งเดี๋ยวเรามาแตะกันทีหลังเรื่องของเจ้าตัวอ่าแมเนจเวอร์ชั่นไวท์เนี่ยจริงๆแล้วคอนเซ็ปต์มันก็จะคล้ายๆกันหมดเลยนะครับ ตัวอย่างเช่นพายตอนน่ะอาจจะรีไลน์ออนรีควายเมนต์แบบเท็กซ์ไฟล์แล้วก็จะมีแบบโฟลเดอร์โฟลเดอร์นึงซึ่งเดี๋ยวเราจะได้เห็นตอนที่เอ่อมาแฮสอนกันแล้วก็อย่างตัวจาวาสคริปต์เนี่ยมันก็อาจจะรีไลน์ออนแพคเกจต่อเจสอนก็จะเห็นได้ว่าทุกๆทุกภาษาอะไรเงี้ยมันก็จะมีคอนเซ็ปต์ของเวอร์ชัวร์มันของมันนะแต่อาจจะใช้ลักษณะไม่เหมือนกันก็เป็นไปได้ทีนี้โอเคผมพูดพอแล้วเดี๋ยวเราไปลองดูตัวอย่างกันดีกว่านะครับโอเค โอเคครับเดี๋ยวสมมติผมอยากจะสร้างโฟลเดอร์มาโฟลเดอร์หนึ่งเรียกว่าเออเวอร์ชั่นนะครับเออเวอร์ชั่นทีชิ่งละกันในโฟลเดอร์เนี้ยมันมีอยู่สองวิธีทั้งหมดหรือว่าการสร้างเวอร์ชั่นของใครตอนนะครับวันนี้เราโฟกัสที่ใครตอนมันจะมีอยู่สองวิธีทั้งหมดวิธีแรกคือใช้คำสั่งใครตอนนะครับลบเอ็มวีเอ็นวีแล้วก็ชื่อเราและ วิธีที่สองนะครับในการสร้าง Virtual Environment คือการใช้ Conda ครับ คือการที่เราใช้ท่าแรกเนี่ยมันจะมีความ Light weight กว่านะ แต่ว่าการที่เราใช้ Conda เนี่ยมันจะสามารถช่วยให้เรา manage พวก dependency ต่างต่างได้ง่ายยิ่งขึ้นละกันเดี๋ยวง่ายยังไงเนี่ยเราลองไปดูกันเริ่มจากท่าแรกก่อนนะครับ ถ้าเราจะสร้าง Virtual Environment โดยการใช้ตัว ไปตอนเนี่ยโดยท่าแรกเนี่ยเราก็พิมพ์ไปเลยไปตอนลบเอ็มนะครับวีเอ็นวีแล้วก็ตั้งชื่อว่าอะไรก็ได้เนี่ยแล้วแต่เราชื่อมิวเรียนวีนะครับอันเนี้ยเราจะเห็นว่ามันมีโฟลเดอร์หนึ่งสร้างขึ้นมาถ้าทุกคนคุ้นคอมเม้นนี้โค้ดจุดคือการเปิดที่บอกมาเรา ก็จะเห็นได้ว่ามันมีโฟลเดอร์นั้นสร้างขึ้นมานะครับ ข้างในก็มีบิลมี activate มีอะไรก็ว่าบางนะครับ วิธีในการที่เราจะ activate ตัว environment นี้นะครับก็คือเป็นการที่เราจะรันตัวสคริปต์ activate นะครับ คอมแมนที่เขาแนะนำก็คือ source นะครับ แล้วก็ชื่อโฟลเดอร์นี้แล้วก็หาตัว activate นะครับได้ ทีนี้เราจะเห็นได้ว่าอะไร pip list มันมี dependency ให้เราแค่สองตัวเอง แต่ถ้าผมออกไปจาก environment นี้นะครับ be activate ปึ๊บมันไม่เหมือนเดิมและมันมี environment อื่นเข้ามาเกี่ยวข้องอ่าทวนคือถ้าเราเข้าไปใน environment ที่ผมเพิ่งสร้างมาใหม่เนี่ยก็คือไอ้เจ้าตัวไพตอนลบเอ็มวีเอ็นวีเนี่ยมันมีหน้าที่อย่างเดียวคือมันมีหน้าที่สร้างโฟลเดอร์นี้ขึ้นมาให้เรานะครับโฟลเดอร์มิวเอ็นวีให้เราแต่มันยังไม่ได้ทำให้เรา activate environment อะไร วิธีที่เราจะแอคทีเวทคือพิมพ์คำสั่งซอสแล้วก็เอออันนี้ถัดมานะครับแล้วเราก็จะสามารถที่จะเข้าไปในที่มีแบบเฟรชนิวเลยอ่ะลองดูใหม่สมมติผมอาจจะที่เวทมันกลับเข้าไปใหม่นะครับอันนี้ผมพิมพ์พริชใช่ไหมครับก็คือเป็นวิธีการดูก็จะไม่มีอะไรในนี้เลยโอเค อันนี้ก็คือจะเป็นพื้นฐานในการสร้าง virtual environment แล้วทีนี้ถ้าเราอยากจะ install อะไรเพิ่มเติมเนี่ยถ้าถัดมาของเราเขาอาจจะเป็นพี่อินสตอลใช่ไหมจบอารีควายเมนต์นอเท็กซ์นะถ้าเรามีแบบเอ่อรีควายเมนต์นอเท็กซ์ในนี้นะครับเราก็อาจจะสร้างมันเข้ามาได้เราก็อาจจะเพิ่มเพิ่มค่อยเพิ่มเข้าไปในโปรเจกต์เราเช่นแพนดาสเวอร์ชั่นอะไรของมันผมไม่พูดแล้วกันเพราะผมไม่รู้เหมือนกันว่ามันจะเป็นอะไรก็ได้ในตอนนี้นะครับอ่าเราเสร็จแล้วเราก็อาจจะอินสตอล dependency ในนั้นนะครับ เท่าเนี้ยเราก็จะเห็นได้ว่าดีเพนเดนซี่ที่เกี่ยวข้องมันก็จะถูกอินสตอลแล้วถ้าเราดีแอคทีเวทเอนไวท์เนี่ยไปอ่าเจ้าตัวดีเพนเดนซี่เนี่ยก็จะออกไปก็จะไม่ถูกใช้งานนะครับทีเนี้ยนี่เป็นท่าหนึ่งในการสร้างเวอร์ชวลเมนท์แต่จริงๆมันมีอีกท่าหนึ่งใช่ไหมครับที่ผมบอกก็คือถ้าใช้คอนด้ามันต่างกันหรือมันช่วยยังไงบ้างนะครับคือไอ้เจ้าท่าการสร้างเอ็นไวท์โดยใช้คำสั่งไพตอนลบเอ็มวีเอ็นวีเนี่ย มันก็จะมีข้อดีและข้อเสียเหมือนกันข้อเสียของมันก็คือว่าเราจะต้องเข้าไปในรีโพซิทอรี่ตรงนี้นะครับในระดับมิวอีเอ็นวีเท่านั้นเพื่อที่จะแอคทิเวทเอ็นไวท์นี้ได้นะสมมุติผมแบบอยู่ในรีโพซิทอรี่อื่นเนี่ยผมก็จะไม่สามารถที่จะพิมพ์มิววีอีวีแล้วก็บินแอคทิเวทได้เพราะว่าผมไม่ได้อยู่ในโลเคชั่นนั้น ข้อเสียของเจ้าตัวการใช้ภาพไพน์ตอนลบเอ็มวีเอ็นวีเนี่ยคือเราจำเป็นจะต้องอยู่ในโลเคชั่นนั้นเท่านั้นเราถึงจะสามารถที่จะแอคทิเวทเวอร์ชวลเมนต์นี้ได้ก็เลยลีดสู่อีกเรื่องหนึ่งก็คือตัวคอนด้าอ่ะทีนี้เรามาดูตัวคอนด้ากันครับสมมุติตัวคอนด้าเนี่ยถ้าผมพิมพ์คำว่าคอนด้าอินโฟดีเอ็นเอสนะครับเราก็จะเห็นได้ว่าผมมีดีเพนเดนซี่เยอะแยะไปหมดเลยนะทีเนี้ยดีเพนเดนซี่ที่มันมีเยอะแยะไปหมดเลยเนี่ย มันก็จะมีเราสามารถที่จะแอคทีเวทตัวนี้ได้หมดเลยไม่ว่าเราจะอยู่ที่ไหนก็ตามสมมุติผมอยากจะแอคทีเวทตัวล่างสุดก็คือโยโร่สิบนะครับผมก็พิมพ์ไปเลยอาจจะดีแอคทีเวทอันเก่าก่อนผมก็อาจจะพิมพ์ไปเลยคนได้ที่เวทโยโร่สิบแปดปึ๊บทีเนี้ยเราก็จะอยู่ในเอ็นไวท์เมนต์ที่เหมือนเราเคยทำงานไปแล้วเราจะเข้ามาได้ค่อนข้างง่ายนะครับโดยที่ไม่ต้องแบบมานั่งสร้าง ใหม่แล้วมันก็จะลีนตามนั้นๆนะครับที่เราสนใจนิดนึงครับหลังบ้านนะครับวิธีการทำงานของเจ้าตัวคอนด้าเนี่ยมันจะช่วยประหยัดเวลาเราก็แล้วกันนะครับในมุมที่ว่าแทนที่มันถ้าเราใช้ภาพภายตอนลบเอ็มบีเอ็มวีเนี่ยมันจะสร้างโฟลเดอร์ให้เราตรงนี้ใช่ไหมแต่ถ้าเราใช้คอนด้าแล้วก็ครีทเอ็นไวท์เนี่ยมันจะสร้างโลเคชั่นนี้ให้เราเดี๋ยวเรามาสร้างตัวตัวอย่างของคอนด้ากัน วิธีการสร้างก็ไม่ซับซ้อนครับก็คือคอนด้าเองแล้วก็ตั้งชื่อของเราไปอาจจะเป็นมิวเทสอะไรก็ว่าไปตอนเวอร์ชั่นสามจุดหนึ่งทีนี้นะครับตัวเวอร์ชั่นก็ถูกสร้างขึ้นเรียบร้อยนะครับเราสามารถที่จะแอคทีเวทมันได้ไม่ว่าเราจะอยู่ตรงไหนของโฟลเดอร์ก็ตามเนี่ยถ้าผมพิมพ์ผิดลิสเห็นไหมมันก็จะเป็นแบบเอ็มที่ ดีเพนซี่ก็จะไม่ได้มีอะไรอยู่ในนี้นะครับเหมือนเหมือนพูดง่ายๆเลยอ่ะคือเราจะใช้ค่าคอนด้าเอ่อหรือเราจะใช้ถ้าใครตอนลบเอ็มวีเอ็มวีก็ได้เนี่ยแล้วแต่เราแต่ไอ้เจ้าตัวไพตอนลบเอ็มวีเนี่ยมันจะมีวันเนี้ยมันจะมีข้อดีตรงที่ว่ามันเอ่อไลท์เวทกว่าแต่ตัวนี้มันต้องไอ้คอนด้าเนี่ยมันจะต้องไปนั่งอินสตอลอะไรเพิ่มนะครับ อยากจะเสียเวลาหรือเอ่อเสียแหลมส่วนเอ่อข้อดีของตัวคอนด้าเนี่ยก็คือมันก็อาจจะง่ายกว่าในการแมเนจดีเพนซี่ก็แล้วกันก็เลือกเอาซึ่งถ้าทุกคนจะเลือกเอาเนี่ยใช้อะไรก็ได้ครับเลือกอย่างใดอย่างหนึ่งที่รู้สึกว่าชอบแล้วขนาดแล้วเดี๋ยวเราไปเจอกันในตอนไปก็แล้วกันวันนี้ก็ลาไปเท่านี้นะครับเดี๋ยวดูกันต่อคลิปหน้า
