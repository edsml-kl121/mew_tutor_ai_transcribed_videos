Exercise นี้กันเพราะฉะนั้นไปดูกันครับเริ่มแรกนะครับก็ recap นิดหน่อยเนาะเรามีการเรียนรู้วิธีการสร้าง Frontend Backend Application แล้วก็มีการ เรียนรู้เกี่ยวกับ API แบบเป็นโพสต์ request เบื้องต้นมาเรียบร้อยแล้วก็มีการต่อ front end กับ back end ต่อยังไงทำ exercise ไปแล้วนะครับเบื้องต้นวันนี้เนี่ยอย่างที่ผมบอกเราอาจจะมาโฟกัสแล้วมาต่อยอดจากที่เราเรียนรู้เรื่องด็อกเกอร์ไปด้วยนะครับว่าเราอาจจะทำการเอาไฟล์ front end นะครับที่เรามีการทำไว้ในรอบที่แล้วเนี่ยมาดีพลอยขึ้นไปในคลาวด์ได้อย่างไรบ้าง ก่อนที่ผมจะลงตัวโค้ดนะครับก็จะมาเล่านะครับในเชิงไวท์บอร์ดก่อนว่ามันมีอะไรแล้วเกิดอะไรขึ้นเริ่มแรกอะครับเราก็อาจจะมีสักหนึ่งโฟลเดอร์ใช่ไหมครับที่มีไฟล์ที่เราอ่ะที่เราสนใจเช่น Apply requirement text ใช่ไหมแล้วก็ด็อกเกอร์ไฟล์อย่างที่เรารู้กันนะครับรอบที่แล้วเนี่ยไอ้ตัวด็อกเกอร์ไฟล์เนี่ยก็จะบอกว่าหรือจะมี instruction ว่าเราจะทำการ build image ยังไงนะครับ ตั้งแต่การ Install Dependency การใช้ Steam Run App ซึ่งเดี๋ยวเราจะได้เห็นกันใน Exercise เนาะ แต่ว่าโอเคเริ่มต้นเนี่ยเราก็จะมีโฟลเดอร์ที่เราสนใจเนาะแล้วเราก็จะทำการ Build Image นะครับขึ้นมาเพื่อให้มันกลายเป็นเจ้าตัว Docker Image ตัวนี้นะครับขึ้นมาเนี่ย Docker Image ตัวเนี้ยมันจะอยู่ในเครื่องของคุณอยู่แต่ว่าเราอะก็จะทำการ Push นะครับ Docker Image เนี้ยเข้าไปในอะไรที่เรียกว่า Docker Registry หรือว่าวันเนี้ยที่เราจะใช้กันก็คือจะเป็น Docker Hub ซึ่งเป็นโอเพ่นซอร์สด็อกเกอร์เรจิสตรีนะครับหลังจากนี้นะครับเราก็ได้เรียนรู้รอบที่แล้วใช่ไหมว่าพอเรามีด็อกเกอร์อิมเมจเก็บอยู่ในด็อกเกอร์เรจิสตรีครับเราสามารถที่จะดึงมันลงมาในแล็บท็อปของเราก็ได้หรือจะดึงมันเข้าไปในคลาวด์ใช่ไหม เช่นวีเอ็มในคลาวด์สักตัวหนึ่งแล้วก็พิมพ์คำสั่งว่าด็อกเกอร์รันเท่านี้มันก็จะทำการรันตัวเว็บแอปพลิเคชันของคุณได้เลยเนาะ แต่วันนี้เนี่ยผมอะกะจะโชว์วิธีการใช้ service service หนึ่งเนาะที่จะทำให้ชีวิตมันง่ายขึ้นคือ service เนี้ยจะมีคาแรคเตอร์คล้ายๆ Google Cloud Run เนาะ ซึ่งมันจะเป็นคาแรคเตอร์เชิงว่าเราเพียงแต่ให้ตัว image ID หรือว่า location ว่า image ที่เราเก็บไว้ใน Docker Hub เนี่ยมันคืออยู่ location อะไรแล้วมันอะก็จะทำการ ดึง image ลงมาอัตโนมัติแล้วก็รัน image นั้นน่ะอัตโนมัติเลยให้กลายเป็น container เราก็จะสามารถเซ็ตพวกจำนวน replica port อะไรอย่างเงี้ยได้นะครับ เรียกได้ว่ามันก็จะมี tools ในการช่วยให้การ deploy service เนี่ยมันทำได้ง่ายขึ้นโดยที่อาจจะไม่ต้องอาศัย service ที่ต้องใช้แรงมากกว่าเช่น EC2 เพราะฉะนั้นวันนี้นะครับเราก็จะใช้ service ที่เรียกว่า render นะครับ ซึ่ง Render.com เนี่ยมันจะเป็น service ที่ฟรี แต่ว่า concept เนี้ยมันสามารถที่จะเอาไปใช้ใน service อื่นได้ เช่น Google Cloud Run เนาะ ที่ทำให้ deployment น่ะมันง่ายขึ้น หรือจะใช้ในที่อื่นอื่นเช่นของ intervest ก็น่าจะมีของ IBM Cloud Code Engine อย่างเงี้ยก็น่าจะมีเหมือนกัน เพราะฉะนั้นเราไปรู้กันดีกว่าครับ วันนี้เราจะทำการ deploy โค้ดก้อนนี้นะครับที่ผมเล่ามาก็คือจริงจริงเป็นไฟล์ front end เหมือนเดิมนี่แหละครับที่อยากจะ deploy ไปให้ทุกคนเนี่ยสามารถที่จะเข้าสู่เว็บแอปพลิเคชันตัวเนี้ยได้เลยนะครับ อันเนี้ยเราเข้าเรามาส่องโค้ดกันนิดหน่อยก่อนที่เราจะเริ่มทำอะไรก็นี่ก็คือจะเป็นไฟล์แอปพลายเดิมที่ถ้าทุกคนคุ้นชินก็จะมีชื่อของแอปมีการเขียนอะไรนิดหน่อยมีรูปภาพอะไรอย่างเงี้ยนะครับ เราอะจะอ่าอินสตอลดีเพนเดนซีนะครับที่เรียกว่ารีควายเม้นท์ดอทที่อยู่ในดีพายรีควายเม้นท์ดอท text ที่เป็นสตรีมลิสนี้ลงไปแล้วก็มันจะมีด็อกเกอร์ไฟล์อยู่ไฟล์หนึ่งที่บอกว่าเอ้ยทวนนิดนึงเนาะก็บอกว่าเอ้ยฉันอยากจะใช้ไพตอนเวอร์ชั่นสามจุดหนึ่งนะดึงอันนี้ลงมาแล้วฉันก็จะสร้างโฟลเดอร์ที่เรียกว่าแอปทีเนี้ยก๊อปปี้ไฟล์รีควายเม้นท์เทคที่อยู่ตรงนี้เข้ามาในแอปดอทพายเนาะเราก็ ทำการอินสตอลดีเพนเดนซี่นี้เสร็จแล้วก็ก๊อปปี้ไฟล์แอปบอทพายมาแล้วก็ทำการรันสตรีมแบบนี้นะครับในคอนเทนเนอร์ใหม่ของเราอ่าเราก็จะทำสิ่งนี้ด้วยกันวันนี้นะครับเพราะฉะนั้นเริ่มแรกนะครับเราทำอะไรยังไงวันนี้เนี่ยก็ต้องบอกเนาะว่าผมจะใช้พอร์ตแมนไม่ได้ใช้ดอกเกอร์แต่ว่าคำสั่งเนี่ยมันจะเหมือนกันเป๊ะเลยแค่แทนคำว่าพอร์ตแมนด้วยดอกเกอร์ข้างหน้าโอเคนะครับเริ่มแรกมาเราก็จะเห็นอ่าเราก็เข้าไปในตัว โค้ดของเราเนาะเราก็ทำการหาโฟลเดอร์ที่เรียกว่าสเตจเอ่อตรีศูนย์สามเว็บแอปพลิเคชันนะครับแล้วก็สเตจวันเลเดอร์ฟันเอ็นพลอยเม้นท์อ่าโอเคเราเข้ามาเรียบร้อยแล้วนะครับทีเนี้ยเราลองมาดูอินสตรักชั่นกันนิดนึงนะครับก่อนที่ผมจะลงจริงๆมันจะมีให้เราทำการด็อกเกอร์ล็อกอินอะไรเงี้ยนะครับซึ่งสิ่งเนี้ย ถูกเขาไว้ไปแล้วในในเซสชั่นก่อนก็ใครยังไม่ได้ล็อกอินเข้าสู่ดอกเกอร์ของตัวเองก็ล็อกอินได้นะครับเราจะเริ่มเลยตั้งแต่การสร้างอิมเมจจนถึงการที่เราจะลองรันมันเทสมันในโลโคของเราแล้วก็ดึกพุชมันเข้าสู่ดอกเตอร์เรจิสตรีแล้วก็ทำการอ่าดีพลอยสิ่งนี้ขึ้นไปในคลาวด์นะครับโอเคเรามาเริ่มกันเลยดีกว่าโอเคเสร็จแรกนะครับเราก็จะพิมพ์พอร์ตแมนบิวเอ็กซ์นะครับแล้วก็บิวแพลตฟอร์ม ซึ่งเราจะสเปคซิฟายว่าเป็นเอมดีในนี้เนาะเพราะว่าดีควายเมนต์ในการดีพลอยอิมเมจขึ้นไปในเรนเดอร์เนี่ยคือเขาอยากให้มันอยู่ในเอมดี 64 นะครับก็เอ่อเราก็พิมพ์ชื่ออิมเมจของเราไปได้เลยนะครับซึ่งตอนนี้ก็อาจจะตั้งชื่อเป็นฟอนเอ็นตอนเล่นถูกแล้วกันอันนี้นะครับมันก็จะไล่ อ่านตัวไฟล์ที่อยู่ในนี้แล้วก็ซ้ำการอ่านดอกเกอร์ไฟล์แล้วก็บิวอิมเมจของเราให้เรียบร้อยเนาะพอเราทำพอร์ตแมนอิมเมจเนี่ยมันก็จะเห็นว่าเรามีอิมเมจละที่เชื่อว่าฟันเอ็นสองนะครับทีนี้ก่อนที่เราจะมาต่อกันเราลองมาเช็คกันดูว่าเราอาจจะลองรันอิมเมจอันนี้ในโลโคของเราว่าได้หรือเปล่าเราก็ลอง รันมันดูโดยคอมแมนนะครับก็คือเป็นพอร์ตแมนรันแล้วก็บอกว่าพอร์ตเนี่ยเป็นแปดห้าศูนย์หนึ่งอ่าแปดห้าศูนย์หนึ่งเพราะอะไรเพราะว่าเราสามารถที่จะเช็คได้นะครับในนี้เอ่อดอกเกอร์ไฟล์ก็คืออยากจะรันมันในแปดห้าศูนย์หนึ่งนี่เป็นที่มาที่ไปแล้วก็บอกชื่อเมจของเราก็คือเป็นฟันเอ็นสองอ่าทีเนี้ยถ้าเราลองเปิดตัวแอปพลิเคชันขึ้นมา โลโค้ดแปดห้าศูนย์หนึ่งเราก็จะเห็นว่าอิมเมจของเราเนี่ยมันถูกรันได้นะครับเรียบร้อยแล้วมันก็ไม่มีปัญหาอะไรเพราะฉะนั้นตอนนี้มันพร้อมและที่จะมานั่งพุชอิมเมจเนี่ยเข้าหาด็อกเกอร์เรจิสตรีของเราโอเคทีนี้นะครับก่อนที่เราจะพุชเนี่ยเราอาจจะต้องแท็กอิมเมจนี้ก่อนซึ่งเดี๋ยวผมจะอธิบายให้ว่าแท็กมันคืออะไรอีกรอบหนึ่งก็คือว่าเราพิมพ์ไปได้เลยนะครับพิมพ์ไปก่อนแท็ก ฟอนต์เอ็นสองเราจะให้ชื่ออีกชื่อหนึ่งนะครับกับฟอนต์เอ็นสองเนี่ยให้มันเป็นชื่อที่มีด็อกเกอร์ฮับยูสเซอร์เนมของเราร่วงขึ้นหน้าซึ่งของผมก็จะเป็นเลขนี้แล้วก็จะเป็นชื่ออีเมจของเราฟอนต์เอ็นสองแล้วก็เรเทสถามว่าทำไมเราจะต้องแท็กอย่างนี้แล้วแท็กนี้มันทำอะไรถ้าเราผมลองกดเข้าไปดูเนาะเราก็จะเห็นได้ว่ามันมีอีเมจ เดียวกันเลยที่มันมีชื่อยูหนึ่งแปดศูนย์ศูนย์แปดห้า front end สองที่มันจะแท็กอีกชื่อหนึ่งให้เรานะครับทำให้เราอะไม่ต้อง build image แล้วอะครับเราก็ทำการพิมพ์ Podman แล้วก็ Push ได้เลย แล้วก็เรื่องอิมเมจของเราเพื่อพุชมันไปเท่านี้นะครับอ่ามันตัวเครื่องของเราอ่ะครับก็จะทำการส่งดอกเกอร์อิมเมจไปสู่ดอกเกอร์ครับ ตอนนี้มันเสร็จเรียบร้อยแล้วเราไปเช็คกันดูครับว่าไอ้เจ้าตัวด็อกเกอร์ฮับเนี่ยมันมีเมชของเราหรือเปล่าก็ถ้าใครยังไม่ใส่ก็ใส่อินได้เลยนะครับโอเคอีเมจของเราเนี่ยมันถูกพุชมาและเลสแต่มิเนตเราอาจจะเอาอีเมจเนี้ยไปรันในตัวเรนเดอร์ดอทคอมนะเรา ที่เราต้องทำก็คือเราเสิร์ชคำว่าเรนเดอร์ดอทคอมได้เลยแล้วเราไปสมัครเขาอะไรก็ได้นะครับมันฟรีอยู่ในการที่เราจะสมัครเขาเท่านี้นะครับเราก็สามารถที่จะเข้าสู่ตัวเรนเดอร์ดอทคอมแล้วนะครับวิธีการที่เราจะใช้ตัวเนี้ยให้เราเข้าไปที่โปรเจคเนาะเราก็หาเอามาไว้วางที่แอดนิวแล้วก็เลือกเป็นเว็บเซอร์วิสนะครับทุกคน environmental variable ตรงเนี้ยเลยจะข้ามไปก่อน แต่ว่าเนี่ยก็อาจจะอธิบายนะครับในสมมุติว่าอนาคตอะครับอยากจะ deploy back end service ที่มียกตัวอย่างเช่นที่เราเคยทำกัน มันมีการ import environmental variable มันก็จะสามารถ set ได้ตรงนี้เนาะ โอเค ทีนี้เราก็กด deploy Web service ได้เลย แล้วถ้าสมมติว่ามันไม่มีปัญหาอะไรนะครับ เจ้าตัวอีเมจเว็บแอปพลิเคชันของเราอะก็จะถูกสร้างขึ้นมาได้โดยเราสามารถที่จะกดลิงก์นี้เพื่อที่จะไปเช็คได้เลยนะครับว่ามันดีพลอยแล้วหรือเปล่าไอ้ตรงเนี้ยจะเป็นล็อกนะครับว่ามันกำลังค่อยๆโปรวิชั่น หรือรัน Dogger image ของเราซึ่งก็เห็นได้ว่าตอนเนี้ยมันไม่มีปัญหาอะไรและมันรันได้ปกติ เพราะฉะนั้นเราก็ลองกดเข้าไปดูในลิงก์นี้โอเคครับตอนเนี้ย service ของเราก็พร้อมแล้วนะครับ เพราะฉะนั้นถ้าเรากดสู่ลิงก์นี้เข้าไปนะครับ เราก็จะเห็นว่า Frontend Application ของเราเนี่ยถูกสร้างขึ้นมาได้เรียบร้อยนะครับ โดยที่ไม่มีปัญหาอะไรทีนี้อยากจะเล่านิดหนึ่งนะครับว่าเราสามารถที่จะปรับ setting พวกเนี้ยได้ถ้าเราจริงจริงเราแบบจ่ายตังค์หรือว่า P มากกว่านี้คือเราก็สามารถที่จะให้ ปรับเปลี่ยนพวกจำนวน resources ได้ให้ CPU หรือว่า Ram เนี่ยมันมากขึ้น หรือเราอยากที่จะไป scale สิ่งนี้ขึ้นมาซึ่งโอเคเนี่ยเห็นไหมผมอาจจะกดไม่ได้เนาะ เนื่องจากไม่ได้เป็น Tier Page แต่ว่ามันสามารถที่จะ set ได้ว่าอยากจะมีกี่ instance นะครับ โดยที่ไม่ต้องไปเหนื่อยกับการเขียน Kubernetes แล้วมันมีกี่คลาส replica อะไรเงี้ยนะครับ มันก็จะช่วยให้ชีวิตเราอะง่ายยิ่งขึ้น แต่โอเคตัวแอปพลิเคชันของเราเนี่ยมัน deploy เสร็จเรียบร้อยแล้ว ถ้าเราไม่ได้อยากให้มันคิดตังค์อะไรเราหรือให้มันชัวร์ชัวร์เรื่องการ save นะครับ เราก็ทำการปิด service นี้ได้เลย โดยเราก็อาจจะไปที่ setting แล้วก็ลงไปตั้งท้ายสุดแล้วกด suspend web service นะครับมันจะได้ไม่ถูกบิวบิวหรือว่าคิดต่างอันนี้ก็คือจะเป็นตัวอย่างแล้วกันนะครับว่าเราจะดีพลอยตัวเรนเดอร์นี้ยังไงนะครับก็พอด็อกเกอร์ image บนเรนเดอร์ยังไงซึ่งอ่าซึ่งก็ลองดูกันได้นะครับวันนี้ก็จบไปแล้วนะครับสำหรับอ่าตอนที่เราจะทำการดีพลอย เว็บแอปพลิเคชันอะไรขึ้นมายกตัวอย่างเช่นฟันเอ็นบนเซอร์วิสเช่นเรนเดอร์ดอทคอมที่มันฟรีก็ถ้าใครชอบคลิปนี้นะครับก็อย่าลืมกดไลค์กดแชร์กดซับสไครบ์แล้วก็เดี๋ยวจะมีเซชั่นตอนถัดมานะครับที่เราจะมาลงอ่าในส่วนอื่นอื่นอีกนะครับแล้วก็รอดูตอนตอนถัดไปวันนี้หวัดดีครับ
